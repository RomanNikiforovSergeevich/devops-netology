### Расшифровка правил игнорирования файлов (.gitignore)
На основе файла `terraform/.gitignore` Git будет игнорировать файлы и папки по следующим правилам масок:
1. `.terraform/` — слэш на конце означает, что игнорируется целиком вся директория со всем её содержимым на любом уровне вложенности.
2. `*.tfstate` — звёздочка означает любое количество любых символов. Игнорируются все файлы с расширением `.tfstate`.
3. `*.tfstate.*` — игнорируются файлы, содержащие в имени `.tfstate.`, после которого идут любые символы (резервные копии состояния).
4. `crash.log` и `terraform.rc` — точное совпадение имени и расширения.
5. `crash.*.log` — файлы, начинающиеся на `crash.` и заканчивающиеся на `.log` с любыми символами посередине.
6. `*.tfvars` и `*.tfvars.json` — любые файлы переменных конфигурации с данными расширениями.
7. `override.tf`, `override.tf.json`, `*_override.tf`, `*_override.tf.json` — локальные файлы переопределений ресурсов.
8. `.terraform.tfstate.lock.info` и `.terraformrc` — служебные файлы, скрытые точкой в начале имени.

## Ветвления в Git (Merge и Rebase)

В ходе выполнения практической работы были успешно изучены механизмы слияния веток двумя популярными способами:
1. **Git Merge** — ветка `git-merge` была успешно объединена с основной веткой `main` автоматически. Создан коммит слияния (Merge commit).
2. **Git Rebase (Interactive)** — ветка `git-rebase` была перенесена на актуальный `main` с помощью интерактивного режима. Два промежуточных коммита были объединены в один с помощью команды `fixup`. Возникшие конфликты в файле `rebase.sh` успешно разрешены вручную.
3. Финальное слияние ветки `git-rebase` в ветку `main` прошло в режиме **Fast-forward** (перемотка) без генерации лишних коммитов.
