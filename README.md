### Расшифровка правил игнорирования файлов (.gitignore)

Git будет игнорировать файлы и папки по следующим правилам масок:

1. `.terraform/` — слэш на конце означает, что игнорируется целиком вся директория с таким именем и всё её содержимое, на каком бы уровне вложенности она ни находилась.
2. `*.tfstate` — звёздочка означает любое количество любых символов. Игнорируются все файлы, имя которых заканчивается на строгое расширение `.tfstate`.
3. `*.tfstate.*` — игнорируются все файлы, в названии которых есть расширение `.tfstate`, после которого через точку идут любые символы (например, файлы резервных копий).
4. `crash.log` и `terraform.rc` — точное совпадение. Игнорируются файлы с конкретно указанным именем и расширением.
5. `crash.*.log` — игнорируются файлы, имя которых начинается на `crash.`, заканчивается на `.log`, а между ними содержатся любые символы.
6. `*.tfvars` и `*.tfvars.json` — игнорируются любые файлы, имена которых заканчиваются на данные расширения.
7. `override.tf`, `override.tf.json`, `*_override.tf`, `*_override.tf.json` — игнорируются файлы с точными именами `override`, а также любые файлы, чьё имя заканчивается на знаки `_override` перед указанными расширениями.
8. `.terraform.tfstate.lock.info` и `.terraformrc` — игнорируются конкретные служебные файлы, имена которых начинаются с точки.
