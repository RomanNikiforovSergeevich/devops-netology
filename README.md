### Игнорируемые файлы Terraform
Благодаря добавленному .gitignore, Git будет игнорировать следующие файлы:
1. Папку `.terraform/` — в неё скачиваются плагины и провайдеры, которые весят много и легко скачиваются заново.
2. Файлы `.tfstate` и `.tfstate.backup` — они содержат текущее состояние инфраструктуры и конфиденциальные данные.
3. Файлы `*.tfvars` — в них записываются секретные переменные, пароли и токены доступа, которые нельзя выкладывать в публичный доступ.
4. Логи ошибок `crash.log` — чтобы не засорять репозиторий техническими отчётами о сбоях.
5. Файлы переопределения `override.tf` — локальные правки конфигурации, нужные только вам.
6. Файлы блокировок `.terraform.tfstate.lock.info` — временные файлы, защищающие состояние во время применения команды terraform apply.
